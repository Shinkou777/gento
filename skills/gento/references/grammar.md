# 片子语法

所有风格共用的规矩。手法最早学自 dario-shabi（Darren Ter，MIT）。

---

## 一张节拍表管所有时间

- BPM 跟音乐预设走。一拍 `BT = 60/BPM`，一小节 `BAR = 4 BT`
- 场景按小节排：`['rule', 1.5, T.quote({...})]`
- 画面动作、音效、镜头震动都写成「场景起点 + 几拍」
- 模板自带音效和震动，改场景长度时三者一起挪

`renderAt(t)` 只看 t 画一帧，不存跨帧状态，随机一律用 `hash(n)`。播放、拖进度、导出拿到的都是同一帧。

---

## 一场一击

- 一个场景只说一件事，有一个主重击
- 主重击落在第 1 拍或第 2 拍
- 次要动作卡半拍或整拍
- 每个看得见的动作都有一声

---

## 结构

常用骨架（30〜60 秒）：

| 段 | 模板 | 长度 |
|---|---|---|
| 冷开场 | `T.open` 四个词，一拍一张 | 1 小节 |
| 海报 | `T.poster` 标题三行 + 章 | 1 小节 |
| 章节卡 | `T.chapter` | 0.5 小节 |
| 内容 | quote / number / bars / list / compare / steps / timeline / talk | 每场 1〜2.5 小节 |
| 结论 | `T.verdict` 音乐停，盖章 | 1.5 小节 |
| 尾声 | `T.outro` 一句话 + 清单 + 出处，可选弹窗 | 2〜3 小节 |

15 秒的片子：冷开场 + 两三场内容 + 结论，不放章节卡。

高潮段给场景加 `{ hot: true }`（律动加密），转暗段加 `{ darkMusic: true }`（和声转暗），写在场景条目第四项。

---

## 框架

给每部片子找一个框架，HUD 的词跟着框架起：案卷（卷宗号、罪状、日期）、说明书（型号、步骤）、病历、判决书、实验报告、菜单、成绩单、产品发布会。

`FILM({ hud: { label: '案卷 No.2026-001' } })`；场景可带 `date: '2025.09'` 显示右上日期框。

---

## 屏幕上的字

- 照 `~/.claude/CLAUDE.md` 写作规则：不写「不是A，是B」，不写金句，不写说教
- 一行里只给一个词上色
- 素材里没有的事实、数字、引语不写；引语和数字在尾声 `source` 或 `note` 写出处
- 自拟的文案，交付时告诉用户是哪几句

---

## 节奏

| 节奏 | 每场 | 适合 |
|---|---|---|
| 快切 | 1 小节，章节卡 0.5 | 短视频开头、清单、数据快报 |
| 标准 | 1.5 小节 | 大多数 |
| 舒缓 | 2〜3 小节 | 岁月静好、讲故事、情绪片 |

节奏也改逐字落下的速度，写在 film.json 的 `pace`。
