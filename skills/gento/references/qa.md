# 质检

`node scripts/check.js <片源目录>`。FAIL 必须改到没有；WARN 逐条看。

## 自动查的

| 项 | 判定 | 常见原因 | 改法 |
|---|---|---|---|
| 渲染报错 | 扫帧（每场开头结尾 + 每秒 10 帧）里任何一帧抛错就 FAIL | 自定义场景除零、负半径、取不到的变量 | 看报错的时刻和场景，改那一场的代码 |
| 字体没加载 | FAIL | 断网、字体名写错 | 查网络；风格包字体名对照 catalog.json |
| 字出画 | 定格帧 FAIL，动画中 WARN | 字太长、自定义场景坐标写死 | 用 fitText / fitBlock；坐标用 L 和 W/H |
| 字互相压 | 定格帧里两段字重叠超过 12% | 自定义场景、实心章压字 | 挪位置；刻意叠印的元素加 `over: true` |
| 字太小 | 小于 19px（1080 基准） | 元数据字号写小了 | 最小 22 |
| 空白偏大 | 版心里最大空白矩形超过风格容忍度 | 字短、图小、版面没填满 | 加主视觉、字加大、字短时模板会居中 |
| 峰值过高 / 偏低 | 峰值高于 -0.3 dB / 低于 -6 dB | 自加音效太响 | 调 g |
| 静音段 | 超过 1 秒的静音（结论和尾声除外） | 音乐选了 none、场景 quiet | 加音效或换预设 |
| 重击没配声 | 镜头震动 ≥ 0.5 的时刻 50ms 内没有 hit/seal/pop/tick/ding | 自定义场景只写了 imp | cues 里补 `k.hit` |
| 片长 | 和 film.json 的 target 差太多 | 小节数算错 | 小节数 ＝ 秒 × BPM ÷ 240 |

装饰性的字（底纹上的坐标、编号）加 `deco: true`，不参与检查。

## 要自己看的

跑 `render.js --sheet` 出联系表，用 Read 看：

1. 强调色落在同色系底上看不清（模板里用了 `accentOn`，自定义场景要自己用）
2. 字的意思、错别字、日文假名和汉字混排是否自然
3. 同一片里风格是否一致：自定义场景有没有用风格零件
4. 人物、图标有没有被字压住
5. 每一场只有一个主重击

## 回归

改引擎、改风格包、加新东西之后：

```bash
node scripts/test.js --matrix
```
